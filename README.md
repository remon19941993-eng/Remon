# صوت الحق السوري

منصة إعلامية سورية مستقلة لعرض الأخبار والتقارير والتحليلات، مع واجهة عربية حديثة وتجربة استخدام مناسبة للهاتف والحاسوب.

## الرؤية

تقديم الأخبار والمعلومات بوضوح ومسؤولية، مع الاهتمام بالدقة والتحقق من المصادر واحترام خصوصية المستخدمين.

## أقسام المنصة المخطط لها

- الصفحة الرئيسية وآخر الأخبار.
- تصنيفات الأخبار والتقارير والتحليلات.
- صفحة مستقلة لكل خبر مع المصدر وتاريخ النشر.
- لوحة إدارة للمحررين المعتمدين لإضافة المحتوى وتعديله ومراجعته.
- نظام صلاحيات يحصر النشر في الإدارة والمحررين المعتمدين.
- تصميم متجاوب للهواتف والأجهزة اللوحية والحواسيب.
- تطبيق أندرويد في مرحلة لاحقة.
- دعم البث المباشر عند إعداد خدمة البث.

## التقنية المقترحة

- Next.js وTypeScript للواجهة ولوحة الإدارة.
- Supabase وPostgreSQL للمصادقة وقاعدة البيانات، بعد إعداد المشروع وسياسات الأمان.
- React Native وExpo لتطبيق أندرويد في مرحلة لاحقة.

## حالة المشروع

المستودع في مرحلة التأسيس. هذه الوثيقة تصف الخطة الأولية فقط؛ لم يتم بعد تنفيذ الميزات المذكورة أو اختبارها أو نشرها.

## مبادئ العمل

- التحقق من الأخبار والمصادر قبل النشر.
- حماية بيانات المستخدمين وعدم وضع كلمات المرور أو مفاتيح الخدمات السرية في المستودع.
- استخدام صلاحيات واضحة للإدارة والمحررين.
- اختبار تسجيل الدخول والنشر وإدارة المحتوى قبل الإطلاق.

## اللغة

العربية، مع دعم اتجاه الكتابة من اليمين إلى اليسار (RTL).
